# Foundation Models for Time-Series Forecasting

## Overview

Foundation models are pretrained on massive collections of time-series datasets and support zero-shot forecasting.

These models are transforming forecasting in the same way LLMs transformed NLP.

---

## Implemented Models

### TimeGPT

Developed by Nixtla.

Supports:

- Zero-shot forecasting
- Fine tuning
- Multivariate forecasting

---

### Chronos

Developed by Amazon.

Transformer-based forecasting foundation model.

---

### Moirai

Universal forecasting foundation model.

Supports:

- Cross-domain forecasting
- Long horizon forecasting

---

## Best Use Cases

- Enterprise forecasting
- Cross-domain forecasting
- Zero-shot prediction
- Rapid prototyping

---

## Advantages

- Minimal training required
- Strong generalization
- State-of-the-art performance

## Limitations

- Higher inference cost
- Model size requirements
- External API dependency (for some providers)
