# Transformer-Based Forecasting Models

## Overview

Transformers leverage self-attention mechanisms to model long-range dependencies efficiently.

They represent the current state-of-the-art for many forecasting benchmarks.

---

## Implemented Models

### Transformer

Original attention architecture.

---

### Informer

Efficient long sequence forecasting.

---

### Autoformer

Auto-correlation based forecasting.

---

### PatchTST

Patch-based Transformer architecture.

Strong forecasting benchmark.

---

### TimesFM

Google Foundation Time-Series Model.
